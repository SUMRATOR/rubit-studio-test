# Как внести вклад в Rubik Studio

1. Сделайте форк репозитория и создайте ветку: `git checkout -b feature/моя-фича`.
2. Установите зависимости для разработки: `pip install -e ".[dev]"`.
3. Пишите код в стиле проекта:
   - Форматирование и линт: `ruff check .`
   - Типизация: `mypy rubik_studio`
4. Покройте изменения тестами и убедитесь, что `pytest` проходит.
5. Откройте Pull Request с описанием, что изменено и зачем.

## Код поведения

Участвуя в проекте, вы соглашаетесь соблюдать [Code of Conduct](CODE_OF_CONDUCT.md).

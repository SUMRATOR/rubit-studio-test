# Кодекс поведения участников

Мы стремимся сделать участие в проекте комфортным для всех, независимо от
опыта, пола, возраста, религии или национальности.

- Будьте уважительны и конструктивны.
- Критикуйте код, а не людей.
- Недопустимы оскорбления, травля, дискриминация.

Нарушения можно сообщить через Issues репозитория.

Основано на [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
